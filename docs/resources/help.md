# Help Alcazaba - Get help

## Get help

Questions, bugs and ideas go to the repository's
[issues](https://github.com/nonodev96/fastapi-alcazaba/issues/new/choose), each with its own form:

- **A bug:** what happened and what you expected, a minimal example to reproduce it, the
  versions of fastapi-alcazaba, Python, FastAPI and Pydantic, and the backend.
- **A feature:** the problem it would solve before what you propose, and whether it could serve
  one user's data to another or trust data from the backend.

Search the [open and closed issues](https://github.com/nonodev96/fastapi-alcazaba/issues?q=is%3Aissue)
first: somebody may have asked already.

!!! warning "Vulnerabilities"

    Don't open an issue for a vulnerability: report it privately, through a
    [security advisory](https://github.com/nonodev96/fastapi-alcazaba/security/advisories/new).
    The [security policy](../security.md) says what to include and what happens next.

## Help Alcazaba

- **Star the [repository](https://github.com/nonodev96/fastapi-alcazaba)**, so that others find it.
- **Tell what went wrong:** a bug report with a way to reproduce it is already half the fix.
- **Improve the documentation:** a page that didn't answer your question, an example that
  could be clearer.
- **Send a pull request:** [Development - Contributing](../development.md) tells how to set up
  the repository and run the checks.
