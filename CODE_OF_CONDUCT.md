# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
we want a welcoming, harassment-free community for everyone, whatever their background or level of
experience.

Report unacceptable behaviour privately to the maintainers through GitHub (the "Report content"
option, or a private security advisory if it's urgent). Reports are handled confidentially.
