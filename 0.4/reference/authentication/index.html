    Authentication strategies¶

    FastAPIAuth and its strategies. In fastapi_alcazaba.auth; JWTStrategy, OAuth2Strategy and SAMLStrategy in fastapi_alcazaba.auth.strategies.jwt, .oauth2 and .saml, with their extras.

    In the guide: Strategies. In an app: the example.

    fastapi_alcazaba.auth.FastAPIAuth ¶

    FastAPIAuth(*strategies: Strategy, metrics: Metrics | None = None)

    The strategies of an app, and the dependencies that authenticate with them.

    auth = FastAPIAuth(JWTStrategy(...), SessionStrategy(...))

@app.get("/me")
async def me(user: Annotated[User, Depends(auth.authenticate("jwt", "session"))]): ...

    Parameters:

    Name Type Description Default
    strategies Strategy

    the strategies, by their names; more with use.

    		 ()
    metrics Metrics | None

    where to count the outcomes (fastapi_alcazaba.auth); FastAPICache's by default.

    		 None

    use ¶

    use(strategy: S) -> S

    Add a strategy, under its name; returns it, with its own type (github.redirect()).

    authenticate ¶

    authenticate(*names: str, optional: bool = False) -> Callable[..., Awaitable[Any]]

    A dependency that returns the user of the first of these strategies that finds one (all of them, in the order they were added, without names). Without one, a 401 with their challenges (a WebSocket is closed with 1008), or None when optional.

    user async ¶

    user(connection: HTTPConnection, *names: str) -> Any

    The user of the first of these strategies (all of them without names) that finds one; None when none does. For connections that don't go through a dependency.

    fastapi_alcazaba.auth.AuthenticationFailed ¶

    Bases: Exception

    Raised by a strategy whose credentials are in the request but wrong: an expired token, a forged one, an OAuth2 login the provider refused. The message is logged, never sent.

    fastapi_alcazaba.auth.strategies.jwt.JWTStrategy ¶

    JWTStrategy(key: Secrets | None = None, *, jwks_url: str | None = None, algorithms: Sequence[str] = ('HS256',), audience: str | None = None, issuer: str | None = None, leeway: float = 0, required: Sequence[str] = ('exp', 'sub'), verify: Callable[[dict[str, Any]], Any] | None = None, blocklist: TokenBlocklist | None = None, cookie: str | None = None, signing_key: Secrets | None = None, jwks_lifespan: float = 300, name: str = 'jwt')

    Bases: Strategy

    Authenticates by a JWT in Authorization: Bearer <token> (or a cookie), verified with key or the provider's JWKS. The signature, exp, nbf and the claims of required are always checked, aud and iss when given; a token with an aud is refused when no audience is, as it's meant for some other service. alg: none is never accepted.

    Parameters:

    Name Type Description Default
    key Secrets | None

    what verifies the tokens: a secret of at least 32 bytes for HS256, HS384 and HS512 (a list rotates them: the first one signs, all of them verify), or a public key (PEM) for RS256, ES256, EdDSA...

    		 None
    jwks_url str | None

    the provider's JWKS instead of key: its keys are fetched, by the kid of each token, and kept for jwks_lifespan seconds. Needs audience and issuer: the provider signs the tokens of every app it serves with the same keys.

    		 None
    algorithms Sequence[str]

    those accepted; the first one signs what issue makes.

    		 ('HS256',)
    audience str | None

    the aud the tokens must have.

    		 None
    issuer str | None

    the iss the tokens must have.

    		 None
    leeway float

    seconds of tolerance on exp and nbf, for clocks out of step.

    		 0
    required Sequence[str]

    claims a token must have.

    		 ('exp', 'sub')
    verify Callable[[dict[str, Any]], Any] | None

    verify(claims): the user, or None to refuse the token. Async, or a plain function, which runs in a thread. By default the user is the claims themselves.

    		 None
    blocklist TokenBlocklist | None

    refuses the tokens revoked there (by jti, and by sub and iat for "log out everywhere"); tokens then need a jti and an iat.

    		 None
    cookie str | None

    also reads the token from this cookie, for browsers.

    		 None
    signing_key Secrets | None

    what issue signs with, for asymmetric algorithms (the private key); by default the first key, for HMAC ones.

    		 None
    name str

    what FastAPIAuth.authenticate calls it by.

    		 'jwt'

    decode async ¶

    decode(token: str) -> dict[str, Any]

    The claims of token, verified; raises AuthenticationFailed when it isn't valid.

    issue ¶

    issue(subject: str, *, expires_in: int = 900, **claims: Any) -> str

    A token for subject, valid for expires_in seconds, with iat, exp, a random jti, iss and aud when they're set, and claims.

    fastapi_alcazaba.auth.strategies.oauth2.OAuth2Strategy ¶

    OAuth2Strategy(*, name: str, authorization_url: str, token_url: str, client_id: str, client_secret: str | SecretStr, redirect_uri: str, scopes: Sequence[str] = (), userinfo_url: str | None = None, verify: Callable[[dict[str, Any], dict[str, Any] | None], Any] | None = None, client_auth: Literal['basic', 'post'] = 'basic', params: Mapping[str, str] | None = None, secure: bool = True, timeout: float = 10.0, client: Any = None)

    Bases: Strategy

    Authenticates the requests that come back from the provider's login page (the callback): checks their state, exchanges their code for tokens, reads the user's profile, and returns the user that verify makes of them. Other requests carry nothing for it (None): it only goes on the callback route.

    redirect() starts the login: it sends the browser to the provider with a random state and a PKCE challenge, whose verifier waits in a short-lived cookie (HttpOnly, SameSite=Lax, __Host- when Secure). A callback without that cookie or with another state is refused: nobody can log a user in with their own account (login CSRF) nor use a stolen code.

    Parameters:

    Name Type Description Default
    name str

    what FastAPIAuth.authenticate calls it by, and the cookie's name.

    		 required
    authorization_url str

    the provider's login page.

    		 required
    token_url str

    where codes are exchanged for tokens.

    		 required
    client_id str

    the app's id at the provider.

    		 required
    client_secret str | SecretStr

    the app's secret at the provider.

    		 required
    redirect_uri str

    the callback's absolute URL, as registered at the provider.

    		 required
    scopes Sequence[str]

    what to ask the provider for.

    		 ()
    userinfo_url str | None

    where to read the user's profile with the access token; None for none.

    		 None
    verify Callable[[dict[str, Any], dict[str, Any] | None], Any] | None

    verify(tokens, profile): your user, or None to refuse the login. tokens is the token endpoint's answer (access_token, refresh_token, id_token...), profile the JSON of userinfo_url (None without it). Async, or a plain function, which runs in a thread. By default the user is the profile (or the tokens without it).

    		 None
    client_auth Literal['basic', 'post']

    how the app authenticates to the token endpoint: basic (HTTP Basic, RFC 6749's default) or post (in the form).

    		 'basic'
    params Mapping[str, str] | None

    more parameters for the login page (prompt, access_type...).

    		 None
    secure bool

    the cookie is Secure (browsers accept it from http://localhost too).

    		 True
    timeout float

    seconds for each call to the provider.

    		 10.0
    client Any

    the httpx2 client to call the provider with; one of its own by default.

    		 None

    redirect ¶

    redirect(**params: str) -> RedirectResponse

    The response that sends the browser to the provider's login page, with params added to the URL; it sets the cookie that the callback checks.

    fastapi_alcazaba.auth.HTTPBearerStrategy ¶

    HTTPBearerStrategy(verify: Callable[[str], Any], *, realm: str | None = None, name: str = 'bearer')

    Bases: Strategy

    		 required
    realm str | None

    the realm of the 401's challenge, Bearer realm="...".

    		 None
    name str

    fastapi_alcazaba.auth.strategies.saml.SAMLStrategy ¶

    SAMLStrategy(*, entity_id: str, acs_url: str, idp_entity_id: str, idp_sso_url: str, idp_certificate: str | Sequence[str], verify: Callable[[SAMLProfile], Any] | None = None, name_id_format: str | None = None, clock_skew: float = 60, cache: Cache | None = None, name: str = 'saml')

    Bases: Strategy

    Authenticates the requests the IdP posts to the Assertion Consumer Service (the ACS): checks the signature of their response with the IdP's certificate, and that it answers the login this browser started; the user is what verify makes of the profile. Other requests carry nothing for it (None): it only goes on the ACS route.

    redirect() starts the login (SP-initiated: logins the IdP starts by itself aren't accepted). The id of its request waits in a short-lived cookie (__Host-, HttpOnly, Secure, and SameSite=None: the IdP posts to the ACS from its own site), and the answer must carry it.

    Checked on what the signature covers: the issuer, the audience (entity_id), the recipient (acs_url), the request it answers, when it's valid (with clock_skew), and that it's a bearer assertion. Each assertion works once: its id is kept in the cache's backend until it expires, so a copy is refused by every process. Not supported: encrypted assertions, signed requests, single logout.

    Parameters:

    Name Type Description Default
    entity_id str

    this app's entity id at the IdP (its "SP entity id", or "audience").

    		 required
    acs_url str

    the ACS's absolute URL, where the IdP posts its answers.

    		 required
    idp_entity_id str

    the IdP's entity id, the issuer of its answers.

    		 required
    idp_sso_url str

    the IdP's single sign-on URL (HTTP-Redirect binding).

    		 required
    idp_certificate str | Sequence[str]

    the IdP's signing certificate (PEM); a list while it rotates them. signxml refuses expired ones.

    		 required
    verify Callable[[SAMLProfile], Any] | None

    verify(profile): your user, or None to refuse the login. Async, or a plain function, which runs in a thread. By default the user is the SAMLProfile.

    		 None
    name_id_format str | None

    the NameID format to ask for (urn:oasis:names:tc:SAML:1.1:nameid- format:emailAddress...); the IdP's default without one.

    		 None
    clock_skew float

    seconds of tolerance on the validity times, for clocks out of step.

    		 60
    cache Cache | None

    the Cache whose backend remembers the assertions used; FastAPICache's by default. When it fails, logins are refused.

    		 None
    name str

    what FastAPIAuth.authenticate calls it by, and the cookie's name.

    		 'saml'

    redirect ¶

    redirect(relay_state: str | None = None) -> RedirectResponse

    The response that sends the browser to the IdP with an AuthnRequest, and sets the cookie that the ACS checks. relay_state comes back in the profile (a page to return to; check it before redirecting there).

    metadata ¶

    metadata() -> str

    This app's metadata, for the IdP: its entity id, ACS and NameID format.
